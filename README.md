📊 Sales & Financial Executive Dashboard

📌 Project Overview

This project was completed as part of the Data Analyst Internship at Elevate Labs.

The objective of this project was to design an interactive Sales & Financial Executive Dashboard using Power BI that provides business stakeholders with a quick and clear view of sales, profit, profit margin, and order performance.

The dashboard allows users to filter the analysis by Region and dynamically view the impact on key business metrics and sales trends.

---

🎯 Objective

The main objective of this project was to:

- Analyze sales and financial performance.
- Track important business KPIs.
- Create an interactive Power BI dashboard.
- Provide region-wise sales and profit insights.
- Visualize sales trends over time.
- Present business information in a simple and executive-friendly format.

📊 Dashboard Features

1. KPI Cards

The dashboard contains four key performance indicators:

KPI| Description
💰 Total Sales| Overall sales generated
📈 Total Profit| Overall profit generated
📊 Profit Margin %| Profit as a percentage of sales
🛒 Total Orders| Total number of orders

---

2. Region Slicer

An interactive Region slicer is included in the dashboard.

Available regions:

- Central
- East
- South
- West

When a user selects a region, the KPI cards and sales trend chart automatically update according to the selected region.

---

3. Time-Series Analysis

A Line Chart is used to visualize:

«Sum of Sales by Order Date»

This helps stakeholders understand sales performance over time.

📈 Key Figures

The following figures are shown when Region = East:

Metric| Value
Total Sales| 678.78K
Total Profit| 91.52K
Profit Margin| 13.48%
Total Orders| 1.401K

Profit Margin Calculation

The Profit Margin was calculated using:

Profit Margin % = (Total Profit ÷ Total Sales) × 100

For the East region:

Profit Margin = (91.52K ÷ 678.78K) × 100
              ≈ 13.48%
